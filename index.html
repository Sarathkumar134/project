    Rajalakshmi Engineering College · Dept of Mechatronics Engineering · PROJECTASA2026

    Healthcare delivery faces critical challenges in elderly and bedridden patient care. Caregivers often cannot provide round-the-clock assistance, leading to missed medication schedules and delayed responses to patient needs.

    This project presents an AI-Assisted Web-Based Tele-Operated Mobile Robot that delivers medicines from three time-based compartments — Morning, Noon, and Night — using a 6-DOF robotic arm. Caregivers can assist patients from remote locations via the web interface, voice commands, and a live AI-filtered camera feed with OpenCV face blur for patient privacy.

    The system integrates a Raspberry Pi (main controller) and Arduino (sensor and motor control) communicating via serial USB, with PCA9685 for servo control. The Flask Python backend handles login, real-time command processing, medicine scheduling, sensor data, and live camera streaming. Robotic arm movements are recorded and saved per time slot, replayed on button press, voice command, or scheduled timer.

    01Develop a 4WD mobile robot with robotic arm for medicine pick-and-place delivery from 3 compartments (Morning / Noon / Night).
    02Enable remote control via web interface with voice command support and scheduled delivery timers.
    03Implement AI-based face blur on live camera feed to protect patient privacy during remote monitoring.
    04Provide scheduled and on-demand medicine delivery with sensor-based safety using HC-SR04, MPU6050, and MAX9814.
